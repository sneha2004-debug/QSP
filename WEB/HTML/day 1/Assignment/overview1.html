HTMLGeneration

Here are some example files you can use for generating HTML from lists of files and other things. fix-html.pl written by Dan Connolly, is a perl script to legitimize existing HTML files into SGML-abiding HTML (as per the new DTD that Dan created). ls2html.awk is an awk script which will just take a list of names and generate a menu. dir2html is a shell script which generates a menu of pointers to files with particular suffixes in a set of directories. It also includes a README file at the head of the hypertext list if one exists. You can make any variations on these you like of course.
